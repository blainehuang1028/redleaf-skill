01 / 原则

少量规则，贯穿整册。

内容有主权

保留原文、标题与顺序。长文增页，图片保留比例。排版不替作者删改观点。

纸面有分寸

纤维与色差沉在背景里。墨字清晰，批注贴字，装饰留给确实需要它的地方。

整册有连续性

固定字号、边距与页码，一册使用一种批注色。版式随内容变化，阅读习惯保持稳定。

02 / 色彩

一色入纸，各有深浅。

朱砂沿用已确认的东方色参考；苍蓝、苍绿、赭石与藤黄取自中国色。
颜色分成颜料、文字、淡染三种角色。切换主题，查看整组版式的变化。

04 / 版式

内容不同，纸墨相通。

以下是版式样张，演示文字不代表用户经历。实际文章按内容选择版式，不必凑成固定页数。

05 / 使用

把决定写成清楚的规则。

一段很长
自然增页，保留原文。标题与后续内容尽量同页，避免落下一行。
原文有重点
粗体保持粗体；标记文字加淡染。批注贴近字脚，跨行时逐行绘制。
表格或提示词放不下
按行延续，表头可重复。保留代码空格与换行，不截尾、不缩小整页。
文章没有图片
使用纯文字版式；最终交付不保留素材占位，也不生成替代图片。
