# 红笺排版系统

适用：1080 × 1440 的中文图文册。先读产品原则，再按素材选版式。机器值统一在 `assets/tokens.json`，运行 `node scripts/build-tokens.mjs` 生成 CSS。修改主题、字号或间距时同步更新规范与样张。

## 产品原则

让原文在手机上成为愿意读下去的一页纸。

1. **内容有主权。** 保留文字、标题、顺序、语气和 Markdown 语义；换行与分页服务阅读。不能为了版面删一句话、编一句结论或补一句号召。
2. **纸是阅读背景。** 暖书纸承载墨字，纤维与轻微色差退后。纹理不经过文字，不放旧书污渍、折角和水印；缩到手机上首先看清内容。
3. **一册有连续性。** 同一组图共用纸底、字体、边距、页码和一种批注色。版式因内容变化，基础规则不随页改变。
4. **重点有节制。** 粗体表达原文强调，淡染表达 `==标记==`，链接保留链接。不要因为主题好看就自动挑出每段重点。标题原文没有标记时，封面可采用全墨字；按用户授权强调标题片段时不改字。
5. **东方气质来自材料与排版。** 宋体笔画、墨色、朱批与纸面形成风格。印章、山水、云纹、竖排等只在内容确实需要、用户要求时引入。
6. **规则要能执行。** 每种颜色有角色，每档字有用途，每种版式有适用条件。长文增页；图片保留比例；复杂表格优先拆分；不靠缩小整页字号解决溢出。

从 Kami 学习统一设计语言、有限变量、按内容选择表现方式与交付前渲染检查。红笺的独立选择是手机图文、宋黑分工、真实纸纹、传统色批注、原文完整性。Kami 的印刷字号、写作压缩规则和固定油墨蓝不直接套用。

## 字体与层级

字体：思源宋体 SC Medium 500 用于标题和引文；思源黑体 SC Regular 400 用于正文，Bold 700 用于原文粗体。保留 SIL OFL。禁用合成粗体；不能取得真实字重时先解决字体加载，不能静默使用粗体模拟。斜体保留 `em` 语义；中文缺少原生斜体时允许浏览器倾斜，不扩大到普通正文。

| 角色 | px / 行高 | 用法 |
|---|---|---|
| 封面主标题 | 152 / 1.30 | 2–4 行；长标题用标题版式增大内容区，必要时用正文标题档，不偷偷删字 |
| 页内 H1 | 72 / 1.40 | 原文一级标题 |
| H2 | 60 / 1.40 | 小节标题 |
| H3 | 48 / 1.50 | 小标题 |
| H4–H6 | 42 / 1.50 | 保留层级标签，以间距区别，不放大到主标题 |
| 正文 | 42 / 1.78 | 单栏约 20 个汉字；390px 展示宽度下约 15.2px |
| 引用 | 52 / 1.70 | 正文引用；独立引文页可用 68 / 1.70 |
| 代码与长提示词 | 36 / 1.70 | 等宽拉丁字体；中文沿用思源黑体；不改变空格或标点 |
| 图注 | 32 / 1.60 | 图片来源、说明；需来自原文或明确标为排版说明 |
| 页码与署名 | 28 / 1.50 | 不承载关键观点 |

英文字体优先同字体内的拉丁字符。代码中的拉丁字符使用随附的 Noto Sans Mono，中文回退到思源黑体。导出前比较 i/W 实际字宽，确认等宽字体生效。正文不两端强制拉伸；保留自然段与列表缩进。不能机械把长文章的每一段做成大字引文。

## 纸面与节奏

- 左右边距 100px；正文起点 104px；正文内容底界 1280px；页码距底 64px。可用正文高度为 1176px。
- 间距梯度：8 / 16 / 24 / 36 / 52 / 72 / 104px。段间默认 36px，标题后 36–52px。
- 先用留白区分结构；原文 `---` 才输出中性细线。不用每个小节一条红线。
- 截图保持方正、无假设备壳、无阴影；不要给每段文字套卡片。代码、表头、素材占位可用安静实色底。
- 纤维和色差由固定种子绘制，纹理跨主题相同。纸底是红笺自配 #F4EFE3，不给它虚构传统色名。

## 批注笔触

封面笔触贴近文字下缘，允许略压字脚：当前画布高 64px，有色实笔约 38px；画布起点为文字 Range 下沿上移 39px。正文画布高 46px，有色实笔约 28px；起点上移 33px。按浏览器实际字形渲染复核，不能只把 Range 盒边当可见字脚。

笔触在文字背后，正文使用低透明度；封面稍实。跨行标记逐行绘制，不能画一个大矩形跨过行间空白。双线、圈线、感叹号不默认叠加。主题切换只改变颜料色，不改变笔触形状和文章分页。

## 色彩角色与主题

见 [color-system.md](color-system.md)。默认朱砂；只有用户要求换色或主题选择有明确依据时才换主题，不按页轮换。建议只是内容联想，不把某种颜色绑定某种情绪或文化含义为事实。

## 版式路由

| 原文材料 | 版式 | 保留与溢出处理 |
|---|---|---|
| 首个 H1，无题图 | 大字封面 | 完整题目；允许自然断行。不得自动补副标题或口号 |
| H1 + 用户指定封面图 | 图文封面 | 文字和图片各占明确区域；优先 contain；裁切需保留必要信息 |
| 连续段落 | 阅读页 | 连贯单栏；增加页数；段落可跨页，但避免只剩单行 |
| 原文 blockquote | 引用块 / 引文页 | 短引用嵌在正文；长引文自然跨页；作者来源只用原文 |
| 有序列表、操作流程 | 步骤页 | 保留原序号和嵌套关系；不要给没有步骤的文章编数字 |
| 比较或结构化数据 | 表格页 | 保留行列和表头；跨页重复表头并在 QA 排除重复表头计数；宽表先提出拆列方案 |
| 长提示词、代码块 | 提示词页 | 保留全部文本、空格与换行；允许视觉折行，不截尾；超页继续 |
| 用户图片 / 真实截图 | 配图页 | 图放在原文位置；图片完整，图注可读；无素材不代造图片 |

不把这些版式强制串成固定七页。实际页数由用户内容决定。没有结语就没有结语页；没有图就没有占位图进入最终交付。样张中的占位框仅用于展示系统。

## 验证与交付

将真实正文缩到 390px 展示宽度检查阅读；同时查看原尺寸 PNG。检查溢出、孤行、表格、代码、所有图片加载、真实字体与每行批注位置。正文颜色对纸底的对比至少 4.5:1；色块、纹理不作为唯一语义提示。

交付编号 PNG、整组预览 HTML、原文、素材与配置。对比渲染前后文字序列，区分结构性重复（表头、页码）与原文；不能只以截图数量或肉眼看似完整作为原文完整性证明。当前设计系统样张不等于自动分页引擎的验收。
