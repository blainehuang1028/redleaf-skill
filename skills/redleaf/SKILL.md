# 红笺 · Redleaf

让原文在手机上成为愿意读下去的一页纸。暖书纸、墨字、贴字的淡染批注；标题用宋体，正文用黑体。先保留内容，再安排阅读节奏。

## 从用户材料开始

接受 Markdown、用户直接提供的文章，以及用户提供的图片/截图。用户只给散文时先原样保存为 Markdown；不要擅自补标题、摘要、结论或互动尾页。文字、顺序、标题和语气保持原样。内容太长先增页；需要分篇时给出拆分位置，获得用户授权再改原文。

默认 1080 × 1440 PNG，3:4，朱砂主题。一次选择整册主题，参考 [色彩系统](references/color-system.md)；已有明确偏好时直接采用，不反复询问。仅用户要求突出重点时主动选择高亮。

开始新的图文组或调整视觉时读 [排版系统](references/design-system.md)。根据原文选择连续阅读、引用、步骤、表格、提示词、配图的表现方式，不强行凑固定页数或版式顺序。只替换文字的小改动沿用上一组参数。

## 执行

首次使用在本 skill 目录运行：

```sh
npm ci
npm run fonts
npx playwright install chromium
```

字体从固定 Adobe 源提交获取并校验 SHA256，SIL OFL 许可证随附。只有缺失时安装，不修改其他已装 skill。需要 Node.js 22 或以上版本。

```sh
node scripts/render.mjs /absolute/article.md --out /absolute/output/new-run
```

默认首个 H1 作为封面标题，并在正文保留原有标题。没有 H1 时不编造封面。可选参数 `--theme canglan`、`--no-cover`、`--cover-highlight '原题中的片段'`。封面高亮必须是原题的连续片段，且已获用户明确授权。完整参数、配置与重排见 [运行参考](references/rendering.md)。

- `**粗体**` 保留粗体，`==标记==` 是淡染批注。不要把粗体一律换成高亮。
- `<!-- pagebreak -->` 单独一行是手动分页，`---` 仍是分隔线。代码块里的标记不触发分页。
- 使用用户提供的图片，保留原比例与必要上下文。首版不使用图像生成。无图时用纯排版，不创建虚假的产品截图。
- 不自动增加数学公式或 Mermaid 支持；原文此类内容保留为代码/文字并说明当前限制。
- 不能放下的表格单行或不可拆素材会报错。按报错定位素材，提出拆列或另页放图方案；不能静默截断。

## 检查与修改

成功运行后检查 `qa.json` 的文字完整性、代码原样拼接、图片和链接保留、页面边界及字体加载。脚本检查通过后仍要看编号 PNG 和手机宽度预览，尤其是段落衔接、跨行批注、表格、截图细节与字脚的笔触距离。

用户要求“第 3 页划线粗一点”时沿用同一份原文和主题，先定位该页对应的 `data-source`。笔触局部调整使用配置 `pageStyles` 的 `markScale` / `markLift`；其他样式调整在 CSS/主题参数中完成；内容分页使用用户授权的 pagebreak，保留未经修改的原始输入。输出到新目录，不覆盖上一版。不要直接涂改 PNG。

交付编号 PNG、预览 `index.html`、可查看的 `document.html`、`source.md`、素材、`settings.yml`、`manifest.json` 与 `qa.json`。失败目录含 `FAILED.txt`，不是可交付成品。未经用户明确要求，不向小红书或任何外部账号发帖。

## 维护

颜色和尺寸的唯一值源是 `assets/tokens.json`。修改后运行 `node scripts/build-tokens.mjs`，同步规范与样张，再检查实际渲染。纹理和颜料由固定种子绘制；不要为了主题切换随机改变纸纹。

灵感来自 [Kami / tw93](https://kami.tw93.fun/index-zh.html)，色彩参考中国色与东方色。代码复用和字体许可说明见 [来源](references/sources.md)。不同数字色谱的传统色可能异值，不将本系统数值宣称为历史唯一标准。
