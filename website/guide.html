红笺Redleaf
看样张开始使用使用指南

从一篇原稿，
到一叠红笺。

红笺在本地读取 Markdown，导出 1080 × 1440 的连续图片。开始前准备 Node.js 22 或更新版本，以及一份原稿。

下载技能包

一条命令安装

npx skills add blainehuang1028/redleaf-skill --skill redleaf

由开源 Skills CLI 安装。运行后选择所用 Agent。默认安装到当前项目，加 -g 可安装到全局目录。

如需固定版本，可从发布标签安装：

npx skills add https://github.com/blainehuang1028/redleaf-skill/tree/v0.1.0/skills/redleaf

安装命令放入技能文件；首次使用仍需下方的依赖、字体与 Chromium 准备步骤，Agent 可以按技能说明执行。

交给 Agent

解压下载包，将 redleaf 文件夹放入所用 Agent 的 skills 目录。不同工具的目录可能不同，以对应工具的说明为准。也可以直接让 Agent 读取 redleaf/SKILL.md。

把这句话和原稿一起交给它：

请用红笺排版这份 Markdown，保留原文，使用朱砂主题，导出 3:4 图片和预览。

手动准备

在 redleaf 目录中打开终端，依次运行：

npm ci
npm run fonts
npx playwright install chromium

字体来自固定版本的开源字体仓库，下载后校验 SHA256。首次准备需要联网；之后使用本地图片即可离线排版。

排第一篇

node scripts/render.mjs examples/article.md \
  --out ./my-first-redleaf \
  --theme zhusha

输出目录必须是一个新目录，红笺会保留已有结果。打开输出目录的 index.html 检查预览，再取走 01.png、02.png 等编号图片。

五色随文

  • zhusha：朱砂，默认主题。
  • canglan：苍蓝，适合教程与研究笔记。
  • canglv：苍绿，适合阅读与日常观察。
  • zheshi：赭石，适合经验与复盘。
  • tenghuang：藤黄作淡染，苍黄作文字。

强调有度，图文有序

正文用 ==重要的话== 标出淡染。封面强调须取自原题，例如：

node scripts/render.mjs article.md \
  --out ./second-edition \
  --cover-highlight 意有光 \
  --cover-image ./photo.jpg

Markdown 的图片路径相对原稿文件。独立长截图按比例分段到连续页面，原图另存。请把长截图单独放在一个段落中。图片内已有的文字或水印会照原样保留。

留存一份，方便再排

每次输出会保留原始 Markdown、原图、settings.yml、文字 HTML、素材清单和 qa.json。检查通过后仍应看一遍 PNG，特别是表格、截图细节与跨页衔接。

需要局部调整笔触，可在 YAML 配置中设置页码，随后传入 --config settings.yml：

theme: zhusha
pageStyles:
  '3':
    markScale: 1.15
    markLift: 4

markScale 控制粗细，markLift 控制上移距离。更多参数与手动分页说明，见技能包中的 references/rendering.md。

当前边界

数学公式和 Mermaid 不自动执行，原始 HTML 作为文字安全显示。单行过高或过宽的表格会停止并提示调整。红笺负责排版与导出，社交平台发布由你完成。
